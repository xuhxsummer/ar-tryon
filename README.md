# AR 虚拟试衣 · Web Demo

浏览器里实时试衣：摄像头画面 → MediaPipe 姿态识别 + 人像分割 → 服装图片贴合身体，跟着肩膀和躯干一起动。
不需要构建：原生 ES Modules，MediaPipe 从 CDN 加载。

## 运行

```bash
cd /workspace/ar-tryon
python3 -m http.server 5177 --bind 127.0.0.1   # 或 npm start
```

浏览器打开 **http://localhost:5177** ，点「开启摄像头」，允许摄像头权限即可。

> 摄像头只在**安全上下文**里可用：`localhost` 或 HTTPS。直接双击 `index.html`（file://）打不开摄像头，服装素材也加载不了。
> 用手机测试需要部署到 HTTPS（例如 `npx vite --https`、Cloudflare Tunnel、ngrok 等）。

## 功能

| 功能 | 说明 |
|---|---|
| 摄像头 | 默认优先后置，打不开时自动换前置或默认设备；前置画面自动镜像 |
| 姿态识别 | MediaPipe Pose Landmarker **Full**（默认）/ **Heavy** 可切换；优先用 GPU，不行就换 CPU |
| 人像分割 | 默认用 `selfie_multiclass_256x256`，能区分背景、头发、身体皮肤、脸、衣服。服装只画在身体、衣服和配饰区域，不会盖到背景、脸和头发上；这个模型失败时换成 `selfie_segmenter`，再失败就**只用姿态叠加** |
| 平滑 | 用 One Euro Filter 平滑肩、肘、腕、髋的关键点；强度分弱/中/强三档；可以关闭；人体短暂丢失（≤8 帧）时保留上一帧，减少闪烁 |
| 服装变形 | 用肩线和髋线围成的梯形做 10×14 网格，双线性映射到身体上，逐个三角形仿射贴图；跟着肩宽缩放，跟着躯干旋转；袖子按上臂角度绕肩点旋转（袖子跟随） |
| 手臂遮挡 | 前臂挡在躯干前面时，把服装上对应的区域擦掉 |
| 连衣裙 | 髋线以下的裙摆不按人像裁剪，裙摆可以比身体宽 |
| 校准 | 3 秒倒计时后采集 30 帧 T 字姿势，记录肩宽、躯干/肩宽比、髋/肩比（存进 localStorage）；髋部不在画面里时，按这些比例推算髋部位置 |
| 微调 | 透明度、缩放（0.7–1.5×）、上下偏移、重置 |
| 显示 | 镜像、骨架、分割遮罩（青色）、变形网格（调试用） |
| 上传换装 | **把衣服图片拖进画面**，或点左下角「拖入衣服图片换装」选文件，也可以 Ctrl+V 粘贴。图片会立刻替换当前服装：PNG 透明图直接用；JPG 这类图会从边缘按颜色泛洪去掉纯色背景（可以关闭）。程序会根据轮廓自动估算肩点和髋点，并判断是上衣还是连衣裙 |
| 其他 | FPS、推理耗时、模型状态、跟踪状态；摄像头报错时有中文提示；拍照可保存 PNG；手机和桌面布局都适配 |

## 服装素材 `assets/garments/`

- `white-dress.png`：从你提供的商品照片里自动抠出来的白色一字肩连衣裙，是**默认服装**。
- 程序生成的示例：白色 T 恤、红色 T 恤、海军条纹短袖、牛仔外套、玫瑰连衣裙、薄荷绿短袖。
- 每件服装都有一个 JSON：`category`（top/dress）、`anchor`、`naturalShoulderWidth`、`points`（模板图里左右肩、左右髋的像素坐标）。
- `index.json` 决定服装的顺序，排第一的就是默认服装。
- 重新生成：`python3 tools_gen_garments.py`；`python3 tools_extract_dress.py <照片>`（需要 Pillow 和 scipy）。

**添加自己的服装**：把透明 PNG 放进来，写一个同名 JSON 标出肩点和髋点，再把 id 加进 `index.json`。也可以直接在页面上拖入图片。

## 版本

- `@mediapipe/tasks-vision@0.10.14`（jsDelivr：`vision_bundle.mjs` + `wasm/`）
- 模型（Google Storage，`latest`）：`pose_landmarker_full` / `pose_landmarker_heavy`（float16），`selfie_multiclass_256x256`（float32），`selfie_segmenter`（float16，备用）

## 浏览器

- 推荐 **桌面版 Chrome / Edge**，WebGL2 + GPU 推理最快。
- Safari 16.4+ 能用，但 GPU 推理可能会退回 CPU，速度会慢一些。
- 第一次打开要下载大约 10–30MB 的模型，之后浏览器会缓存。

## 已知限制

- 服装是**一张正面 2D 图片**，没有 3D 布料模拟。侧身超过约 45°、转身或背对镜头时会变形，或者显得太窄。
- 手臂遮挡只处理前臂；手放在胸前、抱臂这类复杂遮挡做不到完全准确。长袖外套的袖子可能被人像遮罩裁掉。
- 分割模型的分辨率是 256×256，衣服边缘会有一点软化或锯齿。宽松衣服、长发会影响裁剪效果。
- 自动去背景只适合**纯色或浅色背景**的商品图。复杂背景或带模特的照片，建议先用专业工具抠成透明 PNG。上传图片的肩点和髋点是估算的，需要时用缩放和偏移微调。
- 一次只跟踪 1 个人。光线暗、逆光或离镜头太近（看不到双肩）时，跟踪会变差。
- 低端手机上建议用 Full 模型。Heavy 更准，但帧率明显更低。
